# Animation Examples

A sandbox project for exploring Jetpack Compose animation APIs.

## What's covered

- `AnimatedVisibility` with `SharedTransitionScope` (shared element transitions)
- Icon animations with Animated Vector Drawables and `AnimatedImageVector`
- State animations — `animateColorAsState`, `animateFloatAsState`, `Animatable`
- Position and layout animations
- Complex sequenced animations

## Navigation

Uses [Navigation 3](https://developer.android.com/guide/navigation/navigation3) (`androidx.navigation3`) with type-safe routes.
